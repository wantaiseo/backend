🚀 CiteKit Backend Deployment Guide

This is a complete, step-by-step guide to deploying the CiteKit backend to a Digital Ocean Droplet (VPS). Follow these instructions exactly to ensure a smooth deployment.

INTERNET │ ▼ [ NGINX REVERSE PROXY ] (Handles SSL, Rate Limiting) │ ▼ [ DOCKER CONTAINER: API ] ◄───► [ REDIS ] ◄───► [ DOCKER CONTAINER: WORKER ]

📋 Prerequisites

  • Digital Ocean Account
  • A Domain Name (e.g., yourdomain.com)
  • Access to manage DNS records for your domain
  • SSH Client (Terminal on Mac/Linux, PowerShell/PuTTY on Windows)

Step 1: Create Your Droplet

  1. Log in to Digital Ocean.
  2. Click Create -> Droplets.
  3. Region: Select the datacenter closest to your users (e.g., Bangalore, Singapore, New York).
  4. Image: Choose Ubuntu 22.04 (LTS) x64.
  5. Size: Choose Basic -> Regular Disk.
    • Minimum: $12/month (2GB RAM / 1 CPU)
    • Recommended: $24/month (4GB RAM / 2 CPU) for better performance.
  6. Authentication: Select SSH Key (Highly Recommended) or Password.
  7. Hostname: Give it a name like citekit-backend.
  8. Click Create Droplet.

Note: Once created, copy the IP Address (e.g., 159.203.x.x).

Step 2: Configure DNS

Go to your domain registrar (GoDaddy, Namecheap, Cloudflare, etc.) and add an A Record.

Type Host/Name Value/Target TTL
A api YOUR_DROPLET_IP Auto / 3600

This will point api.yourdomain.com to your new server.

Step 3: Initial Server Setup

Open your terminal and SSH into your new server:

ssh root@YOUR_DROPLET_IP

Run the automated setup script. This installs Docker, configures the firewall, and creates the necessary users.

curl -sSL https://raw.githubusercontent.com/wantaiseo/backend/main/deploy/setup-droplet.sh | bash

Wait for the script to complete. It may take a few minutes to install Docker.

Step 4: Clone & Configure (CRITICAL)

Navigate to the app directory created by the setup script:

cd /home/citekit/app

Clone the backend repository:

git clone https://github.com/wantaiseo/backend.git .

CRITICAL ACTION 1 Configure Environment Variables

You MUST create the .env file and fill in your real secrets. The app will not work without this.

1. Copy the production template:

cp .env.production .env

2. Edit the file:

nano .env

3. CHANGE THESE VALUES:

  • GEMINI_API_KEY: Your Google AI Studio key.
  • SUPABASE_URL & SUPABASE_KEY: Your database credentials.
  • CORS_ORIGINS: EXTREMELY IMPORTANT. Set this to your frontend URL.
    Example: https://your-frontend.vercel.app,https://yourdomain.com
  • JWT_SECRET: Generate a random string (e.g., run openssl rand -hex 32 locally).

Press Ctrl+X, then Y, then Enter to save.

CRITICAL ACTION 2 Update Nginx Configuration

You need to tell the web server what your domain name is.

1. Open the configuration file:

nano nginx/conf.d/api.conf

2. Find every instance of YOUR_DOMAIN.com and replace it with api.yourdomain.com.

Tip: In nano, you can use Ctrl+\ to find and replace.

Press Ctrl+X, then Y, then Enter to save.

Step 5: Launch Application

Run the main deployment script. This builds the Docker containers and starts the services.

./deploy-digitalocean.sh

Success Check: You should see green "Healthy" messages for API, Worker, and Redis.

Test if it's running (via HTTP for now):

curl http://api.yourdomain.com/health/live

You should get: {"status":"ok"}

Step 6: Setup SSL (HTTPS)

Secure your API with a free Let's Encrypt certificate.

./deploy/setup-ssl.sh api.yourdomain.com your-email@example.com

This script will:

  • Request a certificate from Let's Encrypt.
  • Configure Nginx to use HTTPS.
  • Set up auto-renewal.

Verify: Open https://api.yourdomain.com/health/live in your browser. You should see the lock icon 🔒.

Step 7: Connect Frontend

Now that your backend is live, you need to tell your frontend where to find it.

If using Vercel:

  1. Go to your project settings in Vercel.
  2. Navigate to Environment Variables.
  3. Add/Edit VITE_API_URL.
  4. Value: https://api.yourdomain.com (No trailing slash).
  5. Redeploy your frontend for changes to take effect.

Razorpay Webhook

Don't forget to update your Razorpay Dashboard:

  • Webhook URL: https://api.yourdomain.com/webhooks/razorpay

🆘 Troubleshooting

API not responding?

docker-compose -f docker-compose.production.yml logs -f api

CORS Errors in Browser?

Check that CORS_ORIGINS in your backend .env file matches EXACTLY with your frontend URL (check for trailing slashes, they generally shouldn't be there).

Changes not showing up?

If you edited code locally and pushed to GitHub:

# On the server:
git pull
./deploy-digitalocean.sh
